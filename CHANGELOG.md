# Changelog

## 1.4.0 — 2026-10-04

Added center HUD scaling, wingman box sizing/hiding, a fourteen-entry HUD color list, a smooth draggable color wheel, brightness and numeric RGB controls. Added individual color persistence, per-group original-color resets, and shared-color inheritance. Timer digits and wingman arrows/names/callsigns/boxes use dedicated color paths.

Aligned the color panel with the FOV overlay and added matching borders/transparency, green text, wider stacked RGB inputs and twelve list entries per page.

Replaced competing overlay/edge-name update paths with one frame scheduler. User confirmed smooth operation after that change. Continued game coverage is still needed; unresolved enemy and lock-state elements remain excluded.

## 1.3.0

Added corner HUD position/size controls, radar/D-pad/quick-command grouping, portrait background movement, and the F9 overlay shortcut.
