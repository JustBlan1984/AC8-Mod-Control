# Security review - 1.4.0

This self-contained .NET Windows launcher installs bundled Lua mods into a selected ACE COMBAT 8 installation, manages configuration/backups, and provides the documented offline first-use No EAC launch option. UE4SS is separate. Review native/ModService.cs and bundled scripts for exact behavior; build instructions are in BUILD.md.

Antivirus/platform review results for previous executables do not automatically apply to 1.4.0. No new malware-clearance claim is made. Release hashes identify the exact artifacts.
