# Third-party components

The authored launcher uses Python and tkinter. The packaged EXE includes Python's runtime, Tcl/Tk and associated native runtime libraries collected by PyInstaller. PyInstaller provides its bootloader. Their licenses remain with their respective owners.

- Python: https://docs.python.org/3/license.html (the installed Python LICENSE.txt is included here).
- Tcl/Tk: https://www.tcl-lang.org/software/tcltk/license.html
- PyInstaller: https://pyinstaller.org/en/stable/license.html (GPL with bootloader distribution exception).
- UE4SS: https://github.com/UE4SS-RE/RE-UE4SS (separately installed, not included).

Build package versions are recorded in ../requirements-build.txt. This source repository does not redistribute the upstream Python or PyInstaller binaries. This notice is an inventory for review, not a claim that one license covers all components.
